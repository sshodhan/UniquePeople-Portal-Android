# Agent instructions

These instructions apply to every coding agent working in this repo — Claude
Code, Codex, or anything else. Nothing here is Claude-specific.

- **Working agreements:** `CLAUDE.md` is the source of truth despite the name.
  Read it before writing code.
- **Before opening a pull request:** work through `.github/claude-review.md` in
  full and produce the review summary it requires.
- **Issue tracking:** Linear — **Aura Agents** team, **UniquePeople** project
  (<https://linear.app/aura-agents/project/uniquepeople-4e38fda5c15b>), `AUR-NN`
  ids. Set the project when filing; a follow-up inherits the project of its
  parent issue.
- **Learning loop:** `LEARNINGS.md` holds generalized lessons under stable `§N`
  ids. Read the ones covering the area you are changing, and cite them in PR
  descriptions and reviews.

`CLAUDE.md` and `.github/claude-review.md` hold the detail. This file exists so
agents that do not read `CLAUDE.md` by convention still find them.
